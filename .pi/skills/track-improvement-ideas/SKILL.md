# Track Improvement Ideas

Use the `personal-memory` skill to maintain the list titled **Agent improvement ideas backlog**.

- Keep entries terse: one bullet per idea, with an optional short note.
- Add ideas without requiring them to be fleshed out or categorized.
- Update the existing list; never create one note per idea.
- Confirm changes concisely.
